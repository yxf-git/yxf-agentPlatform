# 办公智能体 — 产品设计文档

> 青岛国家高端智能家电创新中心
> 2026-07-30

---

## 一、产品定位

面向公司全员的通用型AI办公助手。以Chat对话为核心交互形式，通过"技能"机制帮助员工高效执行任务，同时沉淀和共享AI使用能力。

### 核心目标

1. **降低AI使用门槛** — 很多员工不了解如何使用AI，通过技能模板让员工无需编写提示词，一键调用即可完成任务
2. **沉淀能力** — 员工将好的AI用法包装成技能，发布到技能市场，实现公司级的能力复用和积累

### 产品形态

Web App，Chat对话形式，不绑定特定业务线，通用场景覆盖。

---

## 二、产品核心概念

| 概念 | 说明 |
|------|------|
| **对话（Chat）** | 员工和AI的交互界面，支持多轮对话、上传文件、联网搜索、沙箱执行 |
| **技能（Skill）** | 预设的Prompt模板 + 结构化输入表单，员工一键调用，不需要自己想提示词 |
| **技能市场（Marketplace）** | 员工发布、浏览、使用他人创建的技能，实现能力共享 |
| **工具（MCP）** | AI可调用的外部工具和服务，扩展智能体的能力边界 |

```

│          │                      │ 技能│市场│工具│文档 │
```

## 四、模块详细设计

### 4.1 对话（Chat）

**基础能力：**
- 多轮对话，支持上下文连续追问
- 流式输出（打字机效果）
- 对话历史保存，可随时回看和继续

**文档能力：**
- 上传文件（PDF、Word、Excel、PPT等常见办公格式）
- AI自动解析文档内容，可对文档提问、总结、提取关键信息
- 支持同时上传多个文件进行对比分析

**联网搜索：**
- AI根据问题自动判断是否需要联网搜索
- 搜索结果带来源链接，可溯源验证

**沙箱执行：**
- 代码生成与执行 — AI生成代码后可在沙箱中直接运行，返回结果
- 数据计算 — 上传Excel后做统计分析、生成图表，在沙箱中跑出真实结果
- 安全隔离 — 代码在沙箱环境中执行，不影响主系统

**输出能力：**
- Markdown渲染（表格、列表、代码块等）
- 一键导出为文档（Word/PDF）
- 长内容支持分段生成

**对话管理：**
- 新建对话 / 历史对话列表
- 对话可重命名、删除、置顶
- 对话中途可切换/启用技能

---

### 4.2 技能（Skill）

**技能组成：**
- **名称 + 图标 + 描述** — 让人一眼看懂这个技能干什么
- **系统提示词** — 创建者预设的Prompt，定义AI的角色、行为和输出格式（使用者不可见）
- **输入表单** — 创建者定义的结构化字段（文本框、下拉选择、文件上传等）
- **关联工具** — 该技能是否需要联网搜索、文档解析、沙箱执行等能力
- **示例对话（可选）** — 展示典型使用效果，降低理解门槛

**使用方式：**
1. 从右栏"技能"tab或技能市场中选择一个技能
2. 填写输入表单（或用对话方式补充信息）
3. AI按技能预设的方式执行任务
4. 执行完后仍可继续追问、调整

**创建方式：**
1. 在"创建技能"页面填写名称、描述、系统提示词
2. 通过表单方式定义输入字段
3. 创建后先自己测试，满意后可选择发布到技能市场
4. 支持版本更新，发布新版后使用者自动获取最新版

**分类标签：**
- 按场景分类：写作类、分析类、翻译类、数据处理类、办公类等
- 创建者可自定义标签

**技能卡片信息：**
- 技能名称
- 简介描述

**右栏"市场"tab：**
- 展示部分技能卡片作为快捷入口
- 底部"查看全部"按钮进入全屏页面

---

### 4.4 工具（MCP）

右栏"工具"tab展示当前可用的工具列表：
- 联网搜索
- 文档解析
- 沙箱代码执行
- 其他通过MCP接入的外部系统和服务

AI在对话过程中根据需要自动调用相关工具，用户无需手动操作。工具tab主要用于查看当前可用工具和连接状态。

---

### 4.5 用户体系

**登录：**
- 对接公司现有账号体系

**个人中心（头像点进去）：**
- 我创建的技能 — 管理、编辑、查看调用数据
- 我收藏的技能 — 管理收藏列表
- 对话记录 — 历史对话的搜索和管理
- 基础设置 — 头像、昵称、默认模型偏好等
